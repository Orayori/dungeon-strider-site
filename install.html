Android install

Install Dungeon Strider

The Android build is installed by hand from a single .apk file rather than through the Play Store. It takes about a minute, and no account is needed.

What you need

  • ◆An Android phone running Android 8.0 (Oreo) or newer.
  • ◆The Health Connect app, if your phone does not already include it. Android 14 and newer include it; on Android 9 through 13, install Health Connect by Google from the Play Store. Without it the game still runs, but it has no steps to count.

1. Download the file

Tap the download button above on the phone you want to play on. Your browser saves a file called dungeonstrider.apk. Check your notifications or the Downloads app if you do not see it.

2. Allow your browser to install apps

Android only lets apps you installed yourself install other apps, so this permission has to be granted once for your browser.

Usually

Open Settings → Apps → Chrome (or whichever browser you used), then Install unknown apps and turn on Allow from this source.

If your phone differs

Some phones offer Settings → Special access → Install unknown apps instead. If you already tapped the downloaded file, Android offers a shortcut straight to the right screen.

3. Install it

  • 1.Open the downloaded dungeonstrider.apk file, from the download notification or the Downloads app.
  • 2.Tap Install.
  • 3.If Play Protect says it cannot verify the app, choose to install anyway. Every app installed outside the Play Store gets that notice.
  • 4.When it finishes, tap Open.

4. Allow the game to read your steps

The game reads steps from Health Connect, read-only. The first time it needs them, Android shows a Health Connect screen listing the data being requested. Allow the Steps permission.

On Android 9 through 13, if you are sent to install Health Connect instead, install it from the Play Store and then return to the game.

You can change or revoke this at any time in the Health Connect app under App permissions, or from the game's own Open Health Connect control. Revoking it only stops the step count; it does not break your save. Read more in the Privacy Policy.

5. Updating to a new version

When a new version is released, download the new .apk and install it over the old one. Do not uninstall first.

  • ◆Your progress lives on the phone, and installing over the top keeps it.
  • ◆Your leaderboard account stays tied to your Google sign-in.
  • ◆If Android asks whether you want to update the existing app, say yes.

If something goes wrong

“App not installed”. An older copy built with a different signing key is usually the cause. Uninstall the old copy, then install again. It can also mean the phone is low on storage.

“This app isn't compatible with your phone”. The game needs Android 8.0 or newer.

Steps stay at 0. Health Connect is missing, or the Steps permission was denied. Install Health Connect on Android 9–13 and allow Steps in its App permissions.

The download will not start. Some browsers block downloads in private or incognito tabs, or on metered connections. Try a normal tab on Wi-Fi.

The Install button is greyed out. The browser permission in step 2 was not granted for the browser you downloaded with.
